# 🐍 Змейка

Классическая «Змейка» для фронтенда: HTML + CSS + vanilla JS (ES-модули) и Canvas 2D.
Без зависимостей, сборки и транспиляции — открывается как обычная статика.

## Запуск

```bash
npm start          # http://localhost:5173
```

Можно и просто открыть `index.html` напрямую: игра использует ES-модули без внешних запросов
и работает как обычная статика. Самому приложению зависимости не нужны.

## Тесты

```bash
npm test           # 19 тестов правил игры (node:test), без зависимостей
npm install        # только для смоук-теста интерфейса (jsdom)
npm run test:dom   # 12 проверок сквозного сценария в jsdom
```

- `test/core.test.mjs` — чистая логика: шаги, еда и бонусы, стены и сквозные стены, столкновения,
  пауза, победа на заполненном поле, скорость, очередь поворотов.
- `test/dom.test.mjs` — всё приложение целиком в jsdom: сценарий из 12 шагов (меню, отсчёт,
  управление, HUD, пауза, проигрыш, рекорды в `localStorage`, настройки, свайпы, D-pad).
  Если jsdom не установлен, тест помечается пропущенным и `npm test` продолжает работать.

## Управление

| Действие | Клавиатура | Тач |
| --- | --- | --- |
| Движение | `←` `↑` `→` `↓` или `W` `A` `S` `D` | свайп по полю, экранный D-pad |
| Пауза / продолжить | `Space`, `Esc` или `P` | кнопки «Пауза» / «Продолжить» |
| Новая партия | `R` или `Enter` | кнопки «Заново» / «Играть снова» |

Партия автоматически ставится на паузу, если переключиться на другую вкладку.

## Возможности

- **Правила:** яблоки дают +10 и удлиняют змейку; скорость растёт с каждым яблоком до предела; в собственный уезжающий хвост врезаться нельзя.
- **Бонусы:** каждое пятое яблоко открывает золотую звезду (+50 и +2 сегмента). У неё есть таймер, последние шаги она мигает.
- **Сложность:** «Легко», «Норма», «Хард» — разная стартовая скорость и ускорение.
- **Режим стен:** обычные стены или сквозные, когда змейка выходит с противоположной стороны.
- **Прогресс:** очки, длина, уровень и рекорд сохраняются в `localStorage` отдельно для каждой сложности.
- **Полировка:** интерполяция движения между шагами (плавно даже на низком FPS), частицы, тряска экрана, звук на Web Audio API, поддержка `prefers-reduced-motion`.
- **Доступность:** полное управление с клавиатуры, видимый фокус, `aria`-атрибуты у переключателей и поля, вёрстка под узкие экраны и `100dvh`.

## Структура

```
index.html            разметка: HUD, поле, оверлеи меню/паузы/финала, D-pad
styles.css            тёмная тема, адаптивная вёрстка, анимации
js/core.js            чистая логика игры (без DOM): шаги, еда, бонусы, стены, счёт
js/render.js          отрисовка на Canvas 2D: сетка, змейка, еда, частицы, тряска
js/audio.js           звуковые эффекты на Web Audio API, без файлов
js/main.js            связка: игровой цикл, ввод, интерфейс, localStorage
package.json          скрипты start/test/test:dom, jsdom только как devDependency
test/core.test.mjs    тесты правил игры (node:test)
test/dom.test.mjs     смоук-тест интерфейса целиком в jsdom
tools/server.mjs      статический сервер для локальной разработки
```

Логика отделена от отрисовки: `js/core.js` ничего не знает про DOM и работает в Node,
поэтому правила игры покрыты тестами без браузера.
